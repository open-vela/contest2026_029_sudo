# 《资料库》参赛实施计划（2 人可分配版）

> 2026 首届 openvela AI 硬件开发者大赛 · 队伍 029「sudo」· 手表应用创新（快应用）
> 基座：`historyband9`（已验证 v1.3.0 工程）· 应用名：**资料库** · 包名：`com.vela.databank`
> 版本：v0.3 · 截止：2026-09-20 作品提交 · 今日：2026-08-11

## 一、总体目标

将已验证的 historyband9 工程改造成参赛作品《资料库》——腕上极速资料检索应用：
- **三大能力**：极速离线检索（引擎 0.5~1s，历史/词典/单位/百科多知识库）＋ service.health 健康数据＋系统功能直达；AI（velaclaw）为可选增强
- **适配主目标**：480×480 圆屏（AIoT IDE 模拟器 `vela-miwear-watch-5.0`），兼容方屏
- **交付物**：源码＋release.rpk＋README＋AI 日志＋演示视频＋介绍文档

## 二、人员分工（2 人，能力互补）

| 角色 | 代号 | 能力 | 职责 | 严禁触碰 |
|---|---|---|---|---|
| **主程** | A | 技术好 | 全部代码开发、引擎与数据包生成、打包、Git 提交、关键调试 | 无 |
| **测试/资料** | B | 技术一般 | 数据收集整理、模拟器测试走查（按脚本）、UI 文案、品牌素材、参赛材料、AI 日志 | **不直接改核心代码**（只做测试报告、提供数据/文案） |

> **协作原则**：A 负责"生产"，B 负责"供给与验收"。B 产出（数据/测试报告/文案）交给 A 落地；A 的每次改动交给 B 回归测试。两人各有一条并行任务流，互不阻塞。

## 三、双人并行任务流（保证同时干活）

```
【A 流（主程）】       引擎整合 → 搜索链 → 健康 → 功能页 → 打包
                                    ↕ 数据交接 ↕
【B 流（测试/资料）】  数据收集 → 文案素材 → 测试走查 → 材料文档 → 日志
```

**每周固定同步点（建议）**：周一/周四 各 20 分钟，A 讲改动、B 报测试结果，用飞书/微信记录。
